## Over time

The 61 edits land one by one, 2 to 30 minutes apart (the last 1039 minutes after the docs went in, at most). Each of the 36 facts the edits change is asked again at each time after the edit that made its current answer. An index re-synced every N minutes is genter's own search over a copy of the docs taken every N minutes from the moment they went in: the same ranking, so only freshness differs. ## Methodology

- genter-cli 0.3.0 at cbf05a6; Node v22.22.0.
- Embeddings: openai/text-embedding-3-small through vercel, the first 256 numbers of each vector.
- The memory that extracts facts: mem0ai 2.2.1 (pip install mem0ai==2.2.1, no extras), its LLM openai/gpt-5-mini and embeddings openai/text-embedding-3-small through ai-gateway.vercel.sh, local vector store; given each of the 277 sections with fact extraction on, 0 of them failed (and 19 extraction replies were not valid JSON, 2 inserts failed: logged by the library, which went on); the oracle arm deleted the memories of the 46 files the edits touched and added them again from after the edits (320 more LLM calls).
- Answers: openai/gpt-4o-mini through vercel, temperature 0.
